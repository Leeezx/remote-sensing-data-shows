# 灌溉行政区统计交互补充修复设计

## 背景

上一轮修复实现了县级着色、县级与乡镇双图层以及统计模式下关闭栅格查询，但仍存在四项交互和数据访问问题：县级悬停样式未可靠恢复、县级切换到乡镇级时县级图层被重新加载、乡镇图层无法稳定接收悬停与点击事件，以及行政区时间序列在 JSON 缺失时仍会回退到实时栅格计算。

## 目标

- 鼠标离开县级或乡镇级区域后，区域恢复其行政统计原始颜色与边界样式。
- 县级统计切换到乡镇级统计时，复用当前县级矢量、县级平均值和颜色映射，不重新请求或重新挂载县级图层。
- 乡镇图层始终位于县级图层之上，能够正常悬停、点击并显示月度和年度统计。
- 行政区统计接口只读取 `data/stats/irrigation_region_series.json`；缺失行政区或周期时返回 404，不进行实时计算。

## 地图图层与交互设计

### 固定图层层级

地图创建两个独立 Leaflet pane：

- 县级行政区 pane 位于下层，用于展示全部县级区域、县级年平均着色和跨县切换。
- 乡镇明细 pane 位于上层，仅展示当前县的乡镇区域。

两个 pane 使用固定 z-index。区域悬停不再调用 `bringToFront()`，避免单个县级路径永久移动到乡镇图层上方并拦截乡镇事件。

### 悬停样式恢复

`RegionOverlay` 为每个要素保存统一的基础样式计算逻辑。`mouseover` 仅应用临时高亮样式；`mouseout` 重新应用该要素当前基础样式，包括：

- 行政区年平均颜色；
- 普通边界样式；
- 当前选中区域样式。

因此鼠标离开后不会遗留临时颜色，同时已点击选中的区域仍保留选中样式。

### 乡镇事件

乡镇 GeoJSON 使用独立的选择回调和颜色映射。乡镇 pane 高于县级 pane，点击事件停止向地图及县级区域传播。点击乡镇后更新 `selectedRegion`，并以 `level=township` 和乡镇 ID 请求月度、年度统计。

## 县级数据复用设计

县级矢量和县级平均值属于整个行政统计会话，而不属于某一个统计层级。加载逻辑调整为：

1. 从栅格模式首次进入任意行政统计模式时，加载一次县级矢量和县级平均值。
2. 在县级与乡镇级统计之间切换时，仅更新交互层级、提示和选中状态，不清空县级数据。
3. 从乡镇级返回县级时，取消正在进行的乡镇请求并清理乡镇明细；县级图层保持原对象引用。
4. 完全关闭行政统计时，才清理县级和乡镇级会话状态。

客户端现有矢量缓存继续保留，用于重新进入统计模式或重新访问已加载县域时避免重复网络请求。

## JSON-only 统计接口

`GET /api/irrigation/series` 只读取 `get_irrigation_region_series()` 返回的 `irrigation_region_series.json` 数据。

- 行政区 ID 不存在：返回 404。
- 行政区存在但请求周期不存在或不是数组：返回 404。
- 数据存在：直接计算响应中的汇总字段并返回；汇总计算只基于已读取的 JSON 数组，不读取矢量文件或栅格文件。

删除路由对 `find_irrigation_vector_feature` 和 `compute_irrigation_region_series` 的回退调用。前端收到 404 后显示“暂无统计数据”，并保留当前行政区选中状态和地图图层。

## 错误与竞态处理

- 县级基础数据加载失败时，统计模式保持开启，地图不恢复栅格查询。
- 新县乡镇分片加载失败时，保留上一次成功显示的乡镇图层。
- 乡镇请求继续使用请求序号防止旧响应覆盖新县选择。
- 统计 JSON 查询失败只清空统计卡片，不移除行政区图层或选中状态。

## 测试设计

### 前端地图测试

- 县级要素 `mouseover` 后应用临时高亮，`mouseout` 后恢复颜色映射生成的基础样式。
- 悬停过程中不调用 `bringToFront()`。
- 县级与乡镇 GeoJSON 分别使用固定 pane，乡镇 pane 层级更高。
- 乡镇要素 hover 能高亮并恢复，click 调用乡镇选择回调且停止传播。

### 页面测试

- 县级统计切换为乡镇级统计时，县级矢量和县级平均值 API 调用次数不增加，县级图层保持加载状态。
- 点击乡镇后，以乡镇层级和乡镇 ID 请求月度、年度统计，并显示统计卡片。
- 乡镇统计 404 时显示“暂无统计数据”，地图图层仍存在。

### 后端测试

- 已存在的县级和乡镇级 JSON 数据正常返回。
- JSON 中不存在的行政区返回 404。
- JSON 中缺失请求周期时返回 404。
- 测试通过 monkeypatch 使矢量查找和实时计算在被调用时抛错，证明接口不会进入实时计算路径。

## 非目标

- 不改变行政区 JSON 的生成方式和文件格式。
- 不重新生成乡镇矢量分片。
- 不调整县级/乡镇年平均图例阈值算法。
- 不修改栅格点查询、框选查询或其他遥感图层行为。
