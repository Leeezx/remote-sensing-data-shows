# 灌溉行政区统计交互回归修复设计

## 背景

乡镇矢量按县分片后出现三项回归：

1. 开启县级或乡镇统计后，栅格点查询、Shift 框选查询及既有查询结果没有立即关闭。
2. 县级统计不再按行政区多年年平均灌溉用水量着色。
3. 乡镇模式点击县域后，县级导航层被乡镇分片替换，其他县全部消失。

调查确认三项根因分别是：

- 页面把统计模式错误定义为 `regionLevel !== null && adminAverages.length > 0`，导致平均值加载前或为空时重新启用栅格交互。
- `backend/precompute_irrigation.py` 只用当前运行级别重写 `irrigation_regions.json`；执行乡镇预计算后，县级区域清单被覆盖为 0 条，而县级时间序列仍有 2,893 条。
- 页面只维护一个 `regionVector`，乡镇下钻时显式清空县级矢量，再用一个县的乡镇分片替换它。

## 目标

- 只要县级或乡镇统计开关处于开启状态，就立即隐藏栅格、关闭点/框选查询，并清理已有查询结果和地图标记。
- 恢复县级多年年平均灌溉用水量分区着色，图例继续使用与灌溉栅格一致的六级百分位划分方法和基础色带。
- 乡镇下钻采用双层显示：全国县级着色层始终保留，所选县乡镇分片叠加在其上。
- 其他县保持县级着色且可点击；点击后直接切换到该县乡镇分片。
- 保留既有按县分片、单片小于 1 MB、乡镇图层少于 500 的性能约束。

## 非目标

- 不恢复全国乡镇全量 GeoJSON 请求。
- 不引入 MVT、PMTiles、WebGL 或新的地图引擎。
- 不改变灌溉统计的多年平均计算口径、月度/年度折线图口径。
- 不重构与灌溉行政区统计无关的栅格、认证或导出功能。

## 方案比较

### 方案 A：县级底层与乡镇覆盖层独立渲染（采用）

县级矢量、县级颜色映射和县级点击回调作为底层长期存在；当前县的乡镇分片、乡镇颜色映射和乡镇点击回调作为上层按需挂载。乡镇层后渲染，因此在所选县内优先接收事件；其他县仍由县级层接收事件。

优点是行政级别边界清晰、切换县只替换最多 499 个乡镇要素，并能直接复用现有 `RegionOverlay`。代价是 `MapView` 需要明确支持两组覆盖层状态。

### 方案 B：把县级和乡镇要素合并为一个 GeoJSON

每次下钻时删除所选县的县级要素，再加入该县乡镇要素。虽然只传一份数据，但混合级别后，样式、标签阈值、选中状态、点击语义和自动缩放都要依赖每个要素的附加字段，耦合更高。

### 方案 C：升级为多层矢量瓦片

扩展性最好，但实现和部署成本显著高于本次回归修复，也超出当前按县分片已经满足的性能目标。

## 状态模型

### 统计模式与数据状态分离

页面使用以下独立语义：

- `isAdminStatsMode = regionLevel !== null`：唯一决定是否隐藏栅格、禁用查询、冻结时间控制和切换统计图例容器。
- `adminStatsLoading`：只表示统计数据请求是否进行中。
- 县级、乡镇 averages/legend 是否为空：只决定对应矢量能否着色，不再改变交互模式。

这样即使平均值加载失败，用户仍然处于行政区统计模式，栅格查询不会意外恢复。

### 双层矢量状态

`IrrigationPage` 分别维护：

- `countyVector`：县级导航与县级统计底层，进入任一行政区统计模式时加载一次并缓存。
- `countyAverages`、`countyLegend`、`countyColorMap`：县级多年平均着色数据。
- `townshipVector`：当前成功加载的县域乡镇分片；未选县时为 `null`。
- `townshipAverages`、`townshipLegend`、`townshipColorMap`：当前县乡镇多年平均着色数据。
- `townshipCounty`：当前已成功展示乡镇分片的县。
- `pendingTownshipCounty`：用户刚点击、正在加载的目标县；用于状态提示，避免请求完成顺序造成跨县覆盖。
- `selectedRegion`：县级模式下为县，乡镇详情层激活后为乡镇。

县级模式只显示县级层。乡镇模式始终显示县级层；选县成功后再显示乡镇层。

## 前端交互设计

### 进入统计模式

1. 用户点击“县级统计”或“乡镇级统计”。
2. `regionLevel` 立即变为非空，`MapView` 同一渲染周期收到 `disableQuery=true` 与 `hideRaster=true`。
3. `MapView` 在 `disableQuery` 由 false 变为 true 时调用查询 reset，并清除 marker 与 rectangle，保证旧结果卡片和图形不残留。
4. 页面加载并缓存县级矢量及县级平均值。
5. 县级统计直接允许选县查看折线图；乡镇统计提示用户选择县域。

### 县级着色

- 后端从县级 annual series 计算各县多年平均值。
- 图例沿用既有设计：对行政区平均值集合使用与栅格动态图例相同的 2%–98% 百分位六档方法和基础色带。
- 这里“一致”指相同的分档算法、六级颜色顺序和插值规则；行政区总量与栅格像元值统计口径不同，因此不直接复制某一栅格时相的数值阈值。
- 无平均值的县保留可点击轮廓，但使用中性填充，不影响其他县着色。

### 乡镇下钻与跨县切换

1. 用户在乡镇模式点击县 A，页面开始请求县 A 的乡镇分片和平均值；县级层保持不变。
2. 请求成功后，将乡镇覆盖层替换为县 A 数据并缩放到县 A；县 A 内由乡镇层优先接收点击。
3. 县 A 之外仍显示县级年平均着色，点击县 B 后启动县 B 请求。
4. 加载县 B 时县级层始终存在。已显示的县 A 乡镇层可保留到县 B 分片成功，成功后原子替换，避免地图闪空。
5. 使用请求序号或取消标记，只允许最后一次县选择写入状态；较慢的旧请求完成后不得覆盖新选择。
6. 县 B 请求失败时保留当前成功显示的乡镇层，并显示县 B 加载失败提示；用户可重试或选择其他县。

“返回县级选择”只清除乡镇覆盖层、乡镇选中和乡镇统计卡片，不清除县级矢量及县级颜色。

### 图层顺序和事件

`MapView` 依次渲染：底图、可选栅格、县级 `RegionOverlay`、乡镇 `RegionOverlay`、查询图形。统计模式下栅格与查询图形均不存在。

- 县级覆盖层：在县级模式选中县；在乡镇模式负责选择或切换县。
- 乡镇覆盖层：仅在所选县范围内存在，负责选择乡镇。
- 两层点击事件都停止向地图冒泡，防止触发点查询。
- 只有乡镇覆盖层触发县域 `fitBounds`；县级底层数据更新不应反复重置视图。

## 后端数据完整性设计

预计算脚本不再用单个 `level_data` 整体覆盖区域清单。写入 `irrigation_regions.json` 时，应从合并后的 `existing` 数据中重建或合并 `county` 与 `township` 两级条目：

1. 保留未参与本次运行的行政级别。
2. 用本次 shapefile 中的名称更新本级条目。
3. 对同一 `(level, id)` 去重。
4. 输出顺序稳定，避免每次运行产生无意义的大范围 diff。

当前已损坏的数据文件需要从仍完整的 `irrigation_region_series.json` 恢复县级 2,893 条区域元数据。恢复操作只重建区域目录，不重新计算栅格统计。

平均值接口继续按 `level` 过滤；乡镇请求仍强制要求 `countyId` 并只返回该县数据，禁止全国乡镇平均值请求。

## 错误处理

- 县级矢量失败：统计模式保持开启和查询禁用，显示矢量不可用提示。
- 县级平均值失败或为空：县级层仍以中性轮廓显示，图例显示错误/空状态，不恢复栅格或查询。
- 乡镇分片失败：保留县级层和上一个成功乡镇层，不清空整个地图。
- 乡镇平均值失败：乡镇边界仍可交互，以中性填充显示；统计序列仍可按点击加载。
- 超过 499 个乡镇要素的分片继续被拒绝渲染。
- 离开统计模式或切换行政级别时，使在途请求失效，避免旧响应污染新模式。

## 测试设计

### 后端

- 预计算县级时保留既有乡镇区域；预计算乡镇时保留既有县级区域。
- 生成的区域目录对 `(level, id)` 去重且顺序稳定。
- 当前县级区域接口返回非空数据，县级平均值返回与县级 series 对应的记录。
- 县级平均值图例保持六档、阈值严格递增，并复用栅格动态图例算法和色带。
- 乡镇平均值缺少 `countyId` 仍返回 422，只返回目标县乡镇。

### 前端页面

- 点击任一统计按钮后，在 averages 尚未返回时，`MapView` 已收到 `disableQuery=true`、`hideRaster=true`。
- averages 为空或失败时，统计模式仍保持查询禁用和栅格隐藏。
- 县级 averages 返回后，县级 `regionColorMap` 非空且图例切换为行政区图例。
- 进入乡镇模式首先只请求县级矢量，不请求全国乡镇数据。
- 点击县 A 后，县级层仍存在，同时挂载县 A 乡镇层。
- 点击县 B 后只替换乡镇层；县级层对象和颜色映射保持不变。
- 县 B 加载失败时县级层及县 A 乡镇层仍存在。
- 乱序响应不会把较早点击的县覆盖到最后选择的县。

### 地图组件

- `disableQuery` 开启时清除查询卡片、marker 和 rectangle，地图点击/Shift 框选不调用查询 API。
- 两个 `RegionOverlay` 同时挂载，乡镇层后渲染；县级层和乡镇层分别调用正确回调。
- 乡镇分片仍执行 499 要素上限保护和县域自动缩放。

## 验收标准

1. 开启县级或乡镇统计后，栅格、点查询、框选查询及旧查询结果立即消失；关闭统计后恢复栅格查询能力。
2. 县级统计显示非空的多年平均着色和六级行政区图例。
3. 乡镇下钻时，县级着色层始终保留；所选县乡镇层叠加显示。
4. 点击其他县可直接切换乡镇分片，期间不出现全国县级区域整体消失。
5. 没有任何无 `countyId` 的全国乡镇矢量或乡镇平均值请求。
6. 单次乡镇分片仍小于 1 MB，地图乡镇要素仍少于 500。
