# 复耕潜力评估板块设计规格

日期：2026-07-26
状态：已完成交互设计确认，待书面规格审核

## 1. 目标

将第三板块 `/reclamation` 从占位页改造成“复耕潜力评估”地图应用。用户进入板块后先在中国范围中识别四个示范区，点击其中一个区域后下钻，并以可交互圆形网格展示该区域的当前与未来复耕情景。

本功能必须在 2 核 4 GB 生产服务器上运行，不依赖生产环境中的 Excel、桌面目录或 `F:` 盘矢量文件。运行时只提供预构建的静态矢量和点数据，所有点位绘制与交互在浏览器端完成。

## 3. 方案选择

### 3.1 已采用方案

采用“离线预处理 + 按示范区拆分的紧凑双情景数据 + 浏览器单 Canvas 图层 + 自适应真实尺度”。

- 初始视图只加载简化中国轮廓和四个示范区。
- 点击区域后只下载该区域数据。
- 单次下载同时包含当前与未来指标，情景切换不再请求服务器。
- 圆点由单一 Canvas 图层批量绘制，不创建数千个 React 组件或 SVG DOM 节点。
- 服务器不解析 Excel、不进行点查询、不生成动态瓦片。

真实全量数据构造为紧凑数组并保留 6 位小数后，双情景 JSON 约 1.69 MB，gzip 约 297 KB。按区域拆分后的单次响应更小，符合 2 核 4 GB 部署约束。

### 3.2 未采用方案

- 逐点 Leaflet/React SVG 图层：实现简单，但会创建大量图层对象、DOM/SVG 节点和事件绑定，浏览器压力更高。
- 服务端动态栅格或矢量瓦片：更适合百万级数据，但增加服务器 CPU、缓存与运维成本，对 19,332 个点过度设计。

## 4. 用户流程

### 4.1 全国定位状态

1. 用户点击主导航中的“复耕潜力评估”。
2. 地图使用现有底图，并叠加简化的中国轮廓线。
3. 四个示范区以同一种高对比实心色进行缓慢脉冲高亮。
4. 地图显示“点击高亮区域查看复耕潜力”的简短引导。
5. 此时不下载任何点数据，也不显示情景按钮、点位图例或指标卡片。

脉冲使用约 1.6 秒的缓入缓出透明度变化，不使用快速闪烁。系统启用 `prefers-reduced-motion` 时关闭动画，仅保留静态高亮。

### 4.2 区域下钻状态

1. 用户点击一个示范区。
2. 地图使用带内边距的 `fitBounds` 平滑缩放到该区域及其数据范围。
3. 所选区域停止脉冲，转为清晰、高对比的边界；其他示范区不参与点位视图。
4. 页面请求该区域的双情景点数据，默认显示当前情景。
5. 左上侧显示“当前情景／未来情景”切换按钮。
6. 右下角显示当前情景颜色对应的图例。
7. 返回全国视图时清空 Canvas 点位和信息卡片，但保留浏览器内已下载区域缓存。

点击任一示范区后，只显示点中心落在该 Polygon 内的数据，不显示全部 19,332 点。

### 4.3 情景切换

- 默认情景：当前情景。
- 当前情景主色：绿色 `#16A34A`。
- 未来情景主色：蓝色 `#2563EB`。
- 切换只更改浏览器状态并重绘同一 Canvas，不发起新网络请求。
- 切换后关闭旧情景的信息卡片，防止数据语义错配。

## 5. 点位表达与交互

### 5.1 自适应真实尺度

1 km² 圆的等面积半径为约 564.19 m。Canvas 点位使用以下规则：

- 高缩放级别按约 564 m 地理半径转换为屏幕半径。
- 低缩放级别将屏幕半径限制为至少 3 px，即至少 6 px 直径。
- 半径只在 `zoomend` 和视图稳定事件后重算，不在每个缩放动画帧重建数据。

这保证区域整体视图中的点位可辨认，同时在继续放大后恢复约 1 km² 的空间含义。

### 5.2 可复耕状态

- 一个情景的四项指标全部为 `-999`：不可复耕，绘制透明内部和当前情景色描边。
- 四项指标全部为有限数：可复耕，绘制当前情景色实心圆和清晰描边。
- 四项指标部分为 `-999`、部分有效：视为源数据错误，构建失败，不生成发布数据。

不可复耕点不打开指标卡片。其圆框仍参与 Canvas 绘制和图例表达。

### 5.3 悬停与点击

- 仅有效点响应悬停高亮和点击。
- 悬停时增加半径和亮色外描边；离开后恢复原样。
- 命中测试由浏览器端轻量空间索引完成，不向后端发送请求。
- 点击有效点后，右上角打开信息卡片。
- 点击其他有效点时原位更新卡片；卡片提供关闭按钮。

信息卡片内容：

- 情景名称
- 经度、纬度
- 复耕价值（千美元）
- 用水消耗（千美元）
- 产量价值（千美元）
- 土壤碳价值（千美元）

卡片中的四项指标固定保留两位小数；经纬度固定保留六位小数。原始传输值不因显示格式而损失精度。

### 5.4 图例

右下角图例包含当前情景颜色和按复耕价值划分的四类：

- 空心圆：不可复耕（四项指标均为 `-999`）
- 0–5：一般复耕区
- 5–10：建议复耕区
- 大于 10：优先复耕区
- 尺度说明：每个圆代表约 1 km × 1 km 范围

情景切换时更新颜色和标题，语义文案保持不变。

## 6. 数据构建与发布产物

新增离线构建脚本，输入源 Excel、示范区 Shapefile 和现有全国县界源，输出项目内可发布数据。源文件保持只读，不被修改。

建议产物：

```text
data/reclamation/
  manifest.json
  regions.geojson
  china_outline.geojson
  points/
    <WRRCD>.json
    <WRRCD>.json.gz
```

### 6.1 `manifest.json`

包含：

- `schemaVersion`
- 构建时间和源文件名，不记录桌面绝对路径
- 指标字段、中文标签与 `thousand_usd` 单位
- 四个示范区的 ID、名称、点数和边界
- 总输入点数、已归属点数、未归属点数和重叠点数
- Excel、示范区 Shapefile 和全国县界源文件的 SHA-256 校验值

### 6.2 点数据格式

每个区域响应包含一次元数据和紧凑点数组：

```json
{
  "schemaVersion": 1,
  "region": { "id": "D030400", "name": "石嘴山至河口镇北岸" },
  "unit": "thousand_usd",
  "points": [
    [108.821328, 41.340040, 11.209537, 39.661720, 51.015999, 13.553890, 0.484387, 17.071856, 26.272863, 14.023105]
  ]
}
```

数组顺序固定为：经度、纬度、当前四指标、未来四指标。前后端类型和解析测试共同锁定该顺序；页面组件只消费解析后的命名对象，不直接依赖数组索引。

### 6.3 中国轮廓

中国轮廓从现有全国县级 Shapefile 在构建期离线融合、转换为 WGS84，并以 0.05° 容差进行拓扑保持简化。生成结果随项目发布，生产运行时不访问 `F:\矢量底图\中国_县\中国_县.shp`。构建必须保留多部件几何，避免丢失源数据中的离岛或非连续区域；生成后的 GeoJSON 必须小于 1 MB。

## 7. API 与缓存

新增后端路由：

- `GET /api/reclamation/regions`：返回中国轮廓、四个示范区、点数和指标元数据。
- `GET /api/reclamation/points/{region_id}`：返回指定示范区的双情景点数据。

运行时行为：

- 路由只读取预构建文件，不解析 Excel、不执行空间运算。
- 成功响应提供 `ETag` 和 `Vary: Accept-Encoding`。概览响应使用 `Cache-Control: public, max-age=300`；点数据使用 `Cache-Control: public, max-age=86400`。
- 构建同时生成 JSON 和预压缩 gzip；客户端接受 gzip 时返回压缩表示，否则返回原始 JSON。
- 未知区域 ID 返回 404。
- 清单或点文件缺失、损坏、版本不兼容时返回明确的服务错误，不现场回退构建。

浏览器使用 `AbortController` 处理快速跨区点击。成功区域响应缓存在页面生命周期内；旧请求即使晚于新请求返回，也不能覆盖当前选择。

## 8. 前端组件边界

- `ReclamationPage`：页面状态、数据加载、所选区域、情景和错误恢复。
- `ReclamationMap`：Leaflet 容器、底图、中国轮廓、示范区边界和视图切换。
- `ReclamationCanvasLayer`：一个 Leaflet Canvas 覆盖层组件，内部以基础 Canvas 绘制全部点、以透明交互 Canvas 只绘制当前悬停高亮；负责半径换算、空间索引、悬停和点击。
- `ScenarioSwitch`：当前／未来情景入口。
- `ReclamationLegend`：右下角情景与可复耕状态图例。
- `ReclamationInfoCard`：右上角点位指标卡片。
- API 服务和共享类型：解析紧凑传输格式并向页面提供命名、类型安全的数据对象。

组件保持单一职责。Canvas 的尺度换算、样式选择、命中测试和传输解析均抽为无 UI 的纯函数，便于单元测试。命中索引使用屏幕坐标均匀网格：每个桶 32 px，查询鼠标所在桶及相邻桶；索引仅在数据或地图视图稳定后重建。

## 9. 错误与空状态

- 初始矢量失败：地图内显示错误说明和“重新加载”按钮，不显示伪造边界。
- 点数据加载中：保留所选区域边界，显示轻量加载状态。
- 点数据失败：清空残留 Canvas 和卡片，保留区域边界并提供重试。
- 区域数据为空：显示“该示范区暂无复耕潜力数据”，不创建空 Canvas。
- 快速跨区切换：取消旧请求并使用请求序号双重防止旧响应覆盖。
- Canvas 初始化失败：页面显示可恢复错误，不退回数千个 SVG 节点的高开销路径。

## 11. 非目标

本轮不包含：

- 多年份时间轴或更多情景。
- 指标分级配色、热力图或统计图表。
- 点位编辑、上传、导出或服务器端查询。
- 动态栅格/矢量瓦片、数据库或 WebGL 地图引擎迁移。
- 修改其他三个业务板块的交互。

## 12. 完成标准

满足以下条件才视为完成：

1. 用户从中国范围中能够清楚识别并点击四个示范区。
2. 点击后只显示该区域内点位，四区点数与构建审计一致。
3. 当前／未来情景切换不增加服务器请求。
4. `-999` 与有效点的透明／实心表达、颜色、悬停和点击符合设计。
5. 右上角卡片显示四项千美元指标，右下角图例含义完整。
6. 最大 8,702 点使用单 Canvas 流畅交互，服务器不承担运行时解析或绘图。
7. 自动化测试、lint、构建和四区真实浏览器验收均通过。
